# Agent skills

Skills that let AI agents carry out the processes this repository describes
for people, above all [CONTRIBUTING.md](../../CONTRIBUTING.md). They follow
the [Agent Skills](https://agentskills.io/specification) format, so Claude
Code, Devin, Codex, Gemini CLI and Pi can all use them. Why and the rules:
[ADR 0028](../../docs/adr/0028-agent-skills.md).

## Adding a skill

1. Create `.agents/skills/<name>/SKILL.md`. `name` in the frontmatter equals
   the folder name, in kebab-case; the first sentence of `description` is
   the skill's goal.
2. Set `metadata.kind` to `step` or `aggregator`.
3. Put scripts in `scripts/` and call them from the repository root, as
   `node .agents/skills/<name>/scripts/<file>`. A skill with scripts needs a
   `## Contract` section: a table with a row per `status` the scripts
   print, starting with the status in backticks.
4. Commit. The pre-commit hook links the skill for Claude Code
   (`.claude/skills/<name>`) and adds it to the list below.

Removing a skill: delete its folder and commit. The hook removes its link.
